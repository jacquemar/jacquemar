## Incantix — Studio Produit Tech

> **Incantix** est un studio technologique dédié à la conception de produits digitaux pour le marché africain — mobile-first, paiement local (Wave · Mobile Money), IA embarquée.

### ImmoAfrik
**La marketplace immobilière de l'Afrique francophone**

_En développement actif · Web · iOS · Android_

Connecter particuliers, agents et agences sur une plateforme unique — mobile-first, prix en FCFA, marchés peu digitalisés.

**Stack**

![Next.js](https://img.shields.io/badge/Next.js_14-333333?style=flat-square&logo=nextdotjs&logoColor=white)
![NestJS](https://img.shields.io/badge/NestJS-333333?style=flat-square&logo=nestjs&logoColor=white)
![Expo](https://img.shields.io/badge/Expo-333333?style=flat-square&logo=expo&logoColor=white)
![Supabase](https://img.shields.io/badge/Supabase-333333?style=flat-square&logo=supabase&logoColor=white)
![Turborepo](https://img.shields.io/badge/Turborepo-333333?style=flat-square&logo=turborepo&logoColor=white)
![Leaflet](https://img.shields.io/badge/Leaflet-333333?style=flat-square&logo=leaflet&logoColor=white)

**Points clés**
- Carte interactive des annonces (web + mobile)
- Recherche multi-critères & alertes sauvegardées
- Multi-rôles : particulier · agent · agence · admin
- KYC — vérification d'identité (badge Vérifié)
- Boost premium via CinetPay
- Analytics par annonce (vues, clics WhatsApp)
- RLS Supabase + fonctions RPC custom

[![Visiter](https://img.shields.io/badge/Visiter-immoafrik.incantix.net-333333?style=for-the-badge&logo=googlechrome&logoColor=white)](https://immoafrik.incantix.net)

### Photo Boutik
**Génération de visuels produits par IA**

_En développement actif · iOS · Android · Web_

Transformer une photo produit brute en visuel de campagne publicitaire professionnel — sans studio, sans photographe, en quelques secondes.

**Stack**

![Expo](https://img.shields.io/badge/Expo-333333?style=flat-square&logo=expo&logoColor=white)
![NestJS](https://img.shields.io/badge/NestJS-333333?style=flat-square&logo=nestjs&logoColor=white)
![Next.js](https://img.shields.io/badge/Next.js-333333?style=flat-square&logo=nextdotjs&logoColor=white)
![PostgreSQL](https://img.shields.io/badge/PostgreSQL-333333?style=flat-square&logo=postgresql&logoColor=white)
![Redis](https://img.shields.io/badge/Redis_+_BullMQ-333333?style=flat-square&logo=redis&logoColor=white)
![AWS](https://img.shields.io/badge/AWS_EC2-333333?style=flat-square&logo=amazonec2&logoColor=white)

**Pipeline IA**
- Gemini Vision → analyse de l'image produit
- Gemini Text → calibrage du prompt ("Soul")
- fal.ai FLUX Pro → génération finale
- Jobs asynchrones via BullMQ, stockage Cloudflare R2

**Points clés**
- Freemium crédit-based · Stripe + CinetPay + Mobile Money
- OTA updates via EAS Update
- Éditeur canvas web (Fabric.js)

<br/>

> Application de gestion de cartes de visite digitales & networking

_En production_

- Gestion de contacts, messages, prise de RDV, QR code, sync cloud
- [connect2card.com](https://connect.incantix.net/)

---

### Vique — SaaS E-commerce
> Plateforme e-commerce SaaS modulaire pour vendeurs africains

_En production_

- **Stack** : Next.js · NestJS · PostgreSQL · Redux Toolkit
- Auth, gestion produits/clients/commandes/codes promo, dashboard admin, API REST
- [Accéder à l'app](https://vique.net)

---

### PrintXpress — Impression en ligne
> Plateforme e-commerce avec personnalisation d'articles photo & print

_En production_

- **Stack** : Next.js · NestJS · MongoDB · Redux Toolkit · AWS S3 · Twilio · Resend
- Commande sans auth, personnalisation articles, dashboard admin, notifications WhatsApp & email

---

### INR+ — Système de suivi médical
> Gestion et suivi des mesures INR pour patients sous anticoagulants

_En production_

- **Stack** : NestJS · React Native
- Sécurité des données, UX simplifiée pour les professionnels de santé
- Projet privé — code non public

---

### AQ54 — Air Quality Dashboard
> Surveillance de la qualité de l'air à Abidjan (capteurs Airqino / CNR)

_En production_

- **Stack** : React · NestJS · NeonDB · Google Platform · Docker
- Visualisation temps réel (PM2.5, PM10, NO2, O3), agrégation horaire/journalière, cartographie, tableaux de données
- Projet privé — code non public

---

### VAS SMS Scolaire

- **Stack** : Linux · Apache · Kannel · PHP · MySQL

## Projets SIG Professionnels

### Portail Cartographique Foncier — AFOR Côte d'Ivoire

_Client : AFOR CI · Échelle : Nationale_

- **Objectif** : Portail pour la gestion des certificats fonciers et la délimitation des territoires de villages à l'échelle nationale
- **Stack** : React · Spring Boot · PostgreSQL + PostGIS · LADM
- Cohérence des données foncières, visualisation multi-échelle, gros volumes de données spatiales

---

### Portail Géo Import Foncier — Orange Côte d'Ivoire

_Client : Orange CI · Échelle : Nationale_

- **Objectif** : Portail géospatial connecté au cadastre ivoirien — déclaration d'import foncier & consultation des immobilisations d'Orange sur le territoire
- **Stack** : Angular · Spring Boot · PostgreSQL + PostGIS · Nginx · Docker · AWS EC2 · GitHub Actions · JWT
- **Infra** : Déploiement containerisé, pipeline CI/CD automatisé, intégration cadastre

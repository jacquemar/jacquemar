### 📸 Photo Boutik
**Génération de visuels produits par IA**

![Status](https://img.shields.io/badge/🟡_En_développement_actif-orange?style=flat-square&labelColor=1a1a2e)
![Platform](https://img.shields.io/badge/iOS_+_Android_+_Web-6366F1?style=flat-square)

Transformer une photo produit brute en **visuel de campagne publicitaire professionnel** — sans studio, sans photographe, en quelques secondes.

**Stack**

![Expo](https://img.shields.io/badge/Expo-000020?style=flat-square&logo=expo&logoColor=fff)
![NestJS](https://img.shields.io/badge/NestJS-EA2845?style=flat-square&logo=nestjs&logoColor=fff)
![Next.js](https://img.shields.io/badge/Next.js-000?style=flat-square&logo=nextdotjs)
![PostgreSQL](https://img.shields.io/badge/PostgreSQL-336791?style=flat-square&logo=postgresql&logoColor=fff)
![Redis](https://img.shields.io/badge/Redis_+_BullMQ-DC382D?style=flat-square&logo=redis&logoColor=fff)
![AWS](https://img.shields.io/badge/AWS_EC2-FF9900?style=flat-square&logo=amazonec2&logoColor=fff)

**Pipeline IA**
- 🤖 Gemini Vision → analyse de l'image produit
- ✨ Gemini Text → calibrage du prompt ("Soul")
- 🎨 **fal.ai FLUX Pro** → génération finale
- ⚡ Jobs asynchrones via **BullMQ**, stockage **Cloudflare R2**

**Points clés**
- 💳 Freemium crédit-based · Stripe + CinetPay + Mobile Money
- 📱 OTA updates via EAS Update
- 🖼️ Éditeur canvas web (Fabric.js)

<br/>
